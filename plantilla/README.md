# Plantilla Beamer

`unab_presentacion.sty` contiene el tema visual reutilizable para presentaciones.
Define:

- Colores institucionales.
- Portada con logos opcionales.
- Pie de pagina por expositor.
- Bloques, titulos y margenes.
- Comandos auxiliares para portada y cierre.

El contenido de cada exposicion debe vivir en `presentacion.tex` o en una copia
de ese archivo.
