\section{Desarrollo y Prácticas en Python}
Durante el curso, fuimos avanzando desde los conceptos más básicos hasta el desarrollo de lógica condicional que da vida al código. 

En la primera etapa del curso (Introducción a Python), aprendí a escribir mis primeros scripts, a manejar variables, cadenas de texto (strings), valores enteros y booleanos. Me pareció muy interesante entender cómo Python almacena las variables y permite verificar o cambiar los tipos de datos comunes de manera sencilla. A continuación, presento un ejemplo básico de definición de variables y verificación de tipos:

\begin{verbatim}
# Creación de variables y comprobación de tipos
nombre_sistema = "Motor de Inferencia"
reglas_totales = 150
es_valido = True

# Verificación en consola
print(f"Sistema: {nombre_sistema} - Tipo: {type(nombre_sistema)}")
print(f"Estado válido: {es_valido} - Tipo: {type(es_valido)}")
\end{verbatim}

En la segunda etapa, me enfoqué en trabajar con tipos de datos más avanzados. Aprendí a utilizar las estructuras integradas de Python, como listas, diccionarios, conjuntos (sets) y tuplas. Fue muy útil descubrir cómo extraer subconjuntos de listas y manipular la información de manera dinámica:

\begin{verbatim}
# Trabajando con listas y modificación de valores
sintomas_paciente = ["fiebre", "tos", "fatiga"]

# Agregando un nuevo elemento a la lista
sintomas_paciente.append("dolor de cabeza")

# Modificando un valor existente mediante su índice
sintomas_paciente[1] = "tos seca"

print("Síntomas actualizados para el diagnóstico:")
print(sintomas_paciente)
\end{verbatim}

Finalmente, en la tercera etapa abordamos el flujo de control y los bucles. Aquí exploramos las declaraciones condicionales y los operadores lógicos para tomar decisiones en el código. Además, pusimos en práctica los bucles \texttt{for} y \texttt{while} iterando sobre listas y diccionarios.

Para poner en práctica esta integración, te comparto un último ejemplo de código donde combinamos diccionarios, lógica condicional (\texttt{if}) y bucles (\texttt{for}) iterando sobre datos para filtrarlos:

\begin{verbatim}
# Creación de un diccionario con información simulada
datos_expertos = {
    "sistema_1": {"estado": "activo", "reglas": 150},
    "sistema_2": {"estado": "inactivo", "reglas": 45},
    "sistema_3": {"estado": "activo", "reglas": 300}
}

# Uso de un bucle for y lógica condicional para filtrar
print("Sistemas activos con más de 100 reglas:")
for nombre, info in datos_expertos.items():
    if info["estado"] == "activo" and info["reglas"] > 100:
        print(f"- {nombre.capitalize()} (Reglas: {info['reglas']})")
\end{verbatim}

Me pareció increíble ver cómo estas estructuras y flujos de control permiten procesar y evaluar condiciones fácilmente. Esto será una base sólida para cuando empecemos a desarrollar sistemas expertos reales que dependan de motores de inferencia y bases de conocimiento.
