Instalación

Qué debes descargar

Este proyecto necesita VS Code, Git, una distribución LaTeX y la extensión LaTeX Workshop.

git --version pdflatex --version

Después de instalar MiKTeX o TeX Live, cierra y vuelve a abrir VS Code para que detecte `pdflatex` en el PATH.

VS Code

Cómo compilar

La carpeta `.vscode/` ya trae una receta para compilar con PowerShell y guardar el PDF en `pdf/`.

1Abre `presentacion.tex` en VS Code.
2Presiona `Ctrl + Shift + P`.
3Ejecuta `LaTeX Workshop: Build LaTeX project`.
4Selecciona `Compilar presentación seleccionada`.
5Revisa `pdf/presentacion.pdf`.
.\compilar.ps1 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\compilar.ps1

Personalización

Tildes, logos e iconos

Español

Tildes directas

Usa `á`, `é`, `í`, `ó`, `ú`, `ñ`, `¿` y `¡` en `presentacion.tex`. Guarda los archivos en UTF-8.

Logos

Portada automática

Reemplaza `assets/img/logo-unab.png` y `assets/img/logo-facultad.png` para cambiar los logos de la portada.

Font Awesome

Iconos en LaTeX

Usa comandos como `\faUser`, `\faCloud`, `\faLightbulb`, `\faCheckCircle` y `\faChartLine`.

\begin{frame}{\faLightbulb \ Idea principal} \item \textbf{\faCheckCircle \ Punto clave:} descripción breve. \renewcommand{\IconosPortada}{\faCloud \hspace{0.5cm} \faServer}

Si los acentos se ven mal, guarda `presentacion.tex` como UTF-8 desde la barra inferior de VS Code.

Soporte

Errores comunes

La mayoría de fallos se resuelven instalando MiKTeX/TeX Live, cerrando VS Code y verificando `pdflatex`.

`pdflatex` no se reconoce

Instala MiKTeX o TeX Live, reinicia VS Code y prueba `pdflatex --version`.

Falta un paquete

Si MiKTeX pregunta si deseas instalarlo automáticamente, acepta.

PowerShell bloquea el script

Usa la receta de VS Code o ejecuta el comando con `-ExecutionPolicy Bypass`.

Los iconos no compilan

Instala o permite instalar el paquete `fontawesome5` desde MiKTeX.

No aparece el PDF actualizado

Verifica que estés compilando `presentacion.tex` y revisa la carpeta `pdf/`.
